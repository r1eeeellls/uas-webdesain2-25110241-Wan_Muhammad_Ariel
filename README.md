**Deskripsi:**
Website ini merupakan Company Profile untuk UMKM kuliner **Daily Ruby Pekanbaru**, sebuah usaha rumahan yang memproduksi risoles premium dengan berbagai varian rasa (siap saji & frozen). Website dibuat sebagai tugas UAS mata kuliah Web Desain 2, bertujuan mempromosikan katalog produk, jaminan kualitas (halal, higienis, tanpa pengawet), serta mempermudah proses pemesanan pelanggan secara online.

## 🥟 Halaman
- **Beranda** — Hero section dengan tagline, running text promo, dan carousel menu terlaris.
- **Katalog Menu** — Daftar produk risoles siap saji dan edisi frozen, lengkap dengan foto, deskripsi, dan harga per item.
- **Tentang Kami** — Brand identity/filosofi usaha (bahan premium, higienis, selalu fresh) serta FAQ seputar produk dan layanan katering.
- **Kontak** — Formulir digital pemesanan, informasi alamat, WhatsApp, Instagram, email, serta embed Google Maps lokasi outlet.

## ⚙️ Fitur JavaScript
- Bootstrap Carousel untuk slider menu terlaris.
- Modal "Quick View" untuk menampilkan detail produk.
- Keranjang belanja interaktif: tambah/hapus item, hitung subtotal & total pembelian otomatis.
- Validasi form kontak dan form pemesanan sebelum submit.

## 🛠️ Teknologi
- HTML5
- CSS3 + Bootstrap 4/5
- JavaScript
